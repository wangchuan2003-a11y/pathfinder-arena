# Pathfinder Arena 2.0.1

从简单寻路演示升级为可保存、可回放的加权搜索实验室。

- 沙地/水域代价，最优总代价与步数分开显示；旧分享链接继续可用。
- 当前节点、待探索边界与 g/h/f 面板；三个可交互教学场景。
- 撤销/重做、本机草稿、JSON 导入导出、双板 PNG 导出。
- 手机浏览/绘图切换、地图放大、精确方向控制和常驻播放栏。
- 修复地图焦点下的工具与播放快捷键，以及绘图和异步导入的时序问题。

验证：32 项核心测试、24 项桌面/手机浏览器测试、应用与测试 TypeScript 检查及生产构建通过。已验证正式网站的加权地形与单步面板。
